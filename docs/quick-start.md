# クイックスタート

## 1. ファイルを開く

XMindを使う場合:

```text
templates/project-review-public-template.xmind
```

XMindを使わない場合:

```text
exports/project-review-public-template.md
```

## 2. 最初に埋める場所

`01 レビュー本体` の `00 エグゼクティブサマリー` を最初に埋めます。

- 総合判定
- 一言結論
- 推奨判断
- 最大リスク
- 次に進める条件

ここが埋まると、会議の目的がぶれにくくなります。

## 3. 会議中の進め方

おすすめは45分です。

| 時間 | 見る場所 | 目的 |
| --- | --- | --- |
| 5分 | エグゼクティブサマリー | 今日の結論と論点をそろえる |
| 10分 | 進捗・成果物・品質 | 事実と証跡を確認する |
| 15分 | 課題・リスク | 意思決定に効くリスクを絞る |
| 10分 | 今日決めること | 決定者と判断を明確にする |
| 5分 | 次アクション | 担当、期限、完了条件を決める |

## 4. 会議後に残すもの

- 決まったこと: `02 意思決定ログ`
- 監視すること: `03 リスク台帳`
- やること: `04 アクショントラッカー`
- 次に改善すること: `06 学び・改善`

## 5. よくある失敗

- 進捗報告だけで終わる
- TODOに担当者がいない
- 期限はあるが完了条件がない
- リスクが「気になること」のままで対応策がない
- 決定ログがなく、後から判断理由がわからない

このテンプレートでは、これらを避けるために枝を分けています。
