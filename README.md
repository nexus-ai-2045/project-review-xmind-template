# Project Review XMind Template

A practical XMind template for project review meetings.

This template is designed to keep reviews focused on decisions, risks, and accountable next actions instead of turning them into status-report meetings.

## Template

- [`templates/project-review-public-template.xmind`](templates/project-review-public-template.xmind)

## What It Covers

- Executive summary
- Project goals and scope
- Progress and milestones
- Deliverables and quality
- Top risks and blockers
- Decision log
- Action tracker
- Stakeholders and RACI
- Lessons learned and template improvement

## How To Use

1. Open the `.xmind` file in XMind.
2. Duplicate it for your project.
3. Start from `00 使い方`.
4. Fill `01 レビュー本体` during the review.
5. Move detailed decisions, risks, and actions into their dedicated sheets.

## Files

- `templates/`: XMind template files
- `docs/`: usage notes
- `tools/`: generation script for rebuilding the template package
